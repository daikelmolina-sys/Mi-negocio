# Manual de Usuario - Mi Negocio (Sistema de Punto de Venta)

¡Bienvenido al sistema **Mi Negocio**! Esta guía te ayudará a entender y utilizar todas las funciones del sistema para administrar tus ventas, inventario y usuarios de forma sencilla.

---

## 1. Acceso al Sistema (Login)

Al ingresar al sistema, deberás iniciar sesión con tus credenciales.
Existen dos tipos de roles:
- **Administrador**: Tiene acceso total a todas las funciones (Reportes, Inventario, Ajustes, Usuarios).
- **Cajero**: Solo tiene acceso a las pantallas necesarias para el trabajo diario (Ventas, Productos, Cajas). Las secciones sensibles estarán ocultas.

**Nota:** Puedes presionar el ícono del "ojito" (👁️) para ver tu contraseña mientras la escribes.

---

## 2. Pantalla de Inicio (Dashboard)

Es la primera pantalla que ves al entrar. Aquí encontrarás un resumen rápido de cómo va tu negocio:
- Ventas del día.
- Productos con bajo stock que necesitan reponerse.
- Accesos rápidos a las funciones más utilizadas.

---

## 3. Módulo de Venta (POS)

Es el corazón del sistema, diseñado para que las ventas sean rápidas.
- **Buscar Productos:** Puedes usar un lector de código de barras o escribir el nombre del producto en la barra de búsqueda.
- **Agregar al Carrito:** Haz clic en los productos para agregarlos a la cuenta del cliente. Puedes ajustar la cantidad usando los botones `+` y `-`.
- **Cobrar:** Una vez agregados los productos, presiona el botón de cobrar. Se abrirá una ventana para ingresar con cuánto está pagando el cliente, y el sistema calculará automáticamente el vuelto (cambio).

---

## 4. Productos e Inventario

- **Productos:** Aquí puedes crear nuevos productos, asignarles su código de barras, precio de costo y precio de venta.
- **Inventario:** En esta sección (solo para administradores) puedes registrar entradas de nueva mercancía, ajustar el stock actual si hay diferencias o registrar pérdidas.

---

## 5. Control de Cajas

El control de caja es fundamental para que el dinero cuadre al final del día.
- **Apertura de Caja:** Al inicio de la jornada, registra el monto base (el "sencillo" o fondo de caja) con el que empiezas.
- **Movimientos:** Durante el día puedes registrar "Retiros" (sacar dinero para pagar un proveedor) o "Ingresos extra".
- **Cierre de Caja:** Al finalizar la jornada, haz el cierre para que el sistema totalice cuánto efectivo y pagos electrónicos deberías tener.

---

## 6. Créditos (Cuentas por Cobrar)

Si le fías (das a crédito) a clientes de confianza, este módulo es para ti.
- Crea clientes y asígnales una línea de crédito.
- En la pantalla de Ventas, podrás seleccionar "Pago a Crédito".
- Aquí podrás ver cuánto debe cada cliente y registrar los abonos o pagos que te vayan haciendo.

---

## 7. Reportes

Exclusivo para administradores. Aquí puedes ver el historial completo de la tienda:
- Ventas por rango de fechas.
- Ganancias netas (calculadas usando el precio de costo vs venta).
- Historial de recibos por si un cliente necesita devoluciones o aclaraciones.

---

## 8. Usuarios y Seguridad

Aquí el administrador puede crear nuevas cuentas para sus empleados.
- Haz clic en **+ Nuevo Usuario**.
- Asigna un nombre de usuario, contraseña y elige el **Rol** (Cajero o Administrador).
- **Nota de seguridad:** Si un cajero intenta acceder a un enlace prohibido (como Reportes) modificando la dirección web, el sistema lo expulsará y lo obligará a iniciar sesión nuevamente para proteger tu información.

---

## 9. Modo Oscuro

Si trabajas de noche o prefieres colores más oscuros, puedes activar el **Modo Oscuro**. Ve al final del menú lateral (a la izquierda) y presiona el botón "🌙 Modo Oscuro". El sistema recordará tu preferencia.

---

**¡Disfruta usando Mi Negocio!** Si tienes alguna duda, no dudes en consultar este documento.
